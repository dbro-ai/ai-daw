# AI-DAW

A web-based Digital Audio Workstation (DAW) with AI tools for music production. This application allows users to create beats, get AI assistance for singing and instrumental production, and export their completed projects.

## Features
- **Music Production**: Create beats with digital instruments.
- **AI Assistance**:
  - AI suggestions for beats and singing.
  - AI-generated digital instruments.
- **Project Management**: Sign up to save projects to your account.
- **Export**: Download completed music projects.

## Tech Stack
- **Frontend**: HTML, CSS, JavaScript
- **Backend**: Node.js, Express.js
- **Database**: MongoDB or Firebase
- **Authentication**: Firebase Auth
- **Audio Tools**: Tone.js, Web Audio API

## Development
1. Clone the repository:
   ```bash
   git clone https://github.com/dbro-ai/ai-daw.git
   ```
2. Navigate to the project folder and install dependencies.
   ```bash
   cd ai-daw
   ```
3. Start building your music projects!
